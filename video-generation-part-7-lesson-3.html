02 / MA MẪU RUN LOG

Chuẩn Hoá Run Log Cho Mọi Thử Nghiệm

Sử dụng mẫu Run Log bên dưới để ghi lại thông số mỗi lần render. Sao chép trực tiếp vào file ghi chú workflow của dự án.

Template: Video Generation Experiment Log

EXPERIMENT_RUN_LOG.MD FORMAT: MARKDOWN 
# Experiment Log: [Project Name / Wan2.2 LoRA Test]
Date: 2026-07-25
Model Base: Wan2.2-T2V-14B
Adapter: sks_person_v1.safetensors (Strength: 1.0)
Prompt Baseline: "sks person, walking down neon street, Tokyo night, 4k cinematic"
Negative Prompt: "blurry, low quality, distortion, static"
Seed: 424242 | Resolution: 1280x720 | FPS: 24 | Steps: 25

---
## Run #01 (Baseline)
- Parameter: Default Baseline (CFG 6.0, Denoise 1.0)
- Outcome: Accepted baseline. High facial consistency, slight motion jitter at frame 40.

## Run #02 (Experiment 1 - Single Variable Change)
- Variable Changed: CFG Scale 6.0 -> 4.5
- Hypothesis: Giảm CFG để chuyển động tự nhiên hơn và bớt nhiễu sát viền.
- Observation: Chuyển động mượt hơn nhưng facial identity giảm nhẹ.
- Decision: REJECTED (Keep CFG 6.0 for identity preservation).

## Run #03 (Experiment 2 - Single Variable Change)
- Variable Changed: Added IP-Adapter Weight 0.35 for pose control
- Observation: Khung hình ổn định hoàn toàn, không bẻ mặt.
- Decision: ACCEPTED (Merge into main production workflow.json).
