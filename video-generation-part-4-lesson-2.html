01 — Khái niệm

Custom Node là gì?

Custom Node là extension do cộng đồng hoặc nhà cung cấp phát hành, được ComfyUI nạp khi khởi động. Nội dung node, dependency và khả năng tương thích thuộc về từng extension; không phải mọi node ngoài core đều có cùng quy trình cài.

Cần biết trước

Bài này yêu cầu hiểu node-graph từ Bài 4.1 — cần biết node là gì và Workflow JSON được cấu trúc ra sao trước khi quản lý custom nodes.

← Xem lại bài trước: Node & Workflow JSON (4.1)

Node Gốc (Core)

Đi kèm ComfyUI

  • KSampler, VAE Encode/Decode
  • CLIP Text Encode, ControlNet Apply
  • Load Checkpoint, Save Image
  • Đi kèm bản ComfyUI tương ứng; vẫn có thể thay đổi theo phiên bản

Custom Node (Mở rộng)

Cài từ cộng đồng

  • AnimateDiff, IP-Adapter, Reactor
  • Chức năng chuyên biệt (video, face, inpaint)
  • Có thể cài qua registry/Manager hoặc theo README của repo
  • Có dependency, model và phạm vi phiên bản riêng

Định nghĩa

Một Custom Node là extension bổ sung node vào ComfyUI. Với cách cài truyền thống nó thường nằm dưới custom_nodes/; các extension hiện đại có thể khai báo metadata qua pyproject.toml. Đừng suy luận tên thư mục từ tên repo: Manager cảnh báo hai tên này có thể khác nhau.

Lưu ý Version & Platform

Tính tương thích của custom nodes phụ thuộc vào phiên bản ComfyUI và platform (local vs cloud). Kiểm tra phiên bản trước khi cài.

03 — Quy trình cài đặt

Cài đặt từng bước

Nhấn Tiếp theo để xem từng bước cài đặt một Custom Node qua ComfyUI Manager.

🗂️

Mở ComfyUI Manager

Trong giao diện ComfyUI, tìm nút Manager. Nếu không thấy, đừng kết luận extension chưa cài: kiểm tra nó có bị disable không, bundle/giao diện hiện tại đặt menu ở đâu, và log khởi động. Chỉ khi xác nhận Manager vắng mặt mới chọn cách cài phù hợp với bản ComfyUI của bạn.

Để cài Manager lần đầu, vào thư mục ComfyUI/custom_nodes, rồi chạy:

git clone https://github.com/Comfy-Org/ComfyUI-Manager.git comfyui-manager
🔍

Tìm kiếm node cần cài

Trong cửa sổ Manager, chọn Install Custom Nodes. Nhập tên node vào ô tìm kiếm — ví dụ VideoHelperSuite hoặc AnimateDiff.

Bạn cũng có thể dùng Install Missing Nodes nếu đang mở một workflow cũ bị thiếu node.

⬇️

Nhấn Install

Nhấn Install chỉ sau khi đã xác minh publisher và README.

Bảo mật: Kiểm tra source/repo của custom node trước khi cài đặt — chỉ dùng từ nguồn đáng tin cậy. Manager có thể chạy requirements.txt hoặc install.py nếu extension cung cấp chúng; đây là mã của extension, không phải bảo đảm an toàn hay tương thích.

Installed chỉ xác nhận thao tác cài trong Manager. Kiểm tra log khởi động, node palette và một workflow tối thiểu trước khi đưa vào job thật.

🔄

Khởi động lại ComfyUI

Khởi động lại ComfyUI để extension vừa cài được nạp. Đây là yêu cầu của quy trình cài Manager; UI hay F5 của trình duyệt không thay thế việc kiểm tra log server.

Sau khi khởi động lại, node mới sẽ xuất hiện trong palette (nhấn đúp chuột phải vào canvas để tìm). Hoàn tất!

04 — Case study

Production brief: nhận workflow I2V bàn giao

Tình huống mô phỏng: một editor nhận workflow 5 giây cho social ad nhưng thiếu VideoHelperSuite. Mục tiêu là khôi phục pipeline có thể kiểm tra, không phải “cài cho hết lỗi đỏ”.

Ràng buộc & A/B

Giữ một biến, đổi một biến

  • Đầu ra: MP4 5 giây, 16:9 cho bản duyệt nội bộ.
  • Input/workflow: JSON bàn giao + ComfyUI và extension đã pin version.
  • Giữ cố định: checkpoint, prompt, seed, resolution, frame count và GPU.
  • Thử nghiệm: chỉ cài một extension thiếu, rồi chạy workflow test tối thiểu.
  • Giới hạn: 12 GB VRAM, 20 phút cho vòng chẩn đoán; đây là budget dự án, không phải benchmark.
  • Đánh giá: log sạch, node xuất hiện, output có đúng số frame/codec dự kiến.
  • Thất bại: import error, node mapping khác, output rỗng hoặc VRAM OOM. Bước sau: rollback snapshot, lấy version workflow, đọc issue/README của extension.

Mô phỏng quyết định

Preflight trước khi cài

Chọn tín hiệu bạn đang có. Kết quả là checklist mô phỏng, không phải kết luận tương thích.

05 — Quản lý & Xử lý lỗi

Vấn đề thường gặp

Custom Node mang lại sức mạnh nhưng cũng có thể gây ra xung đột. Dưới đây là các lỗi phổ biến và cách khắc phục.

Đỏ

Node hiển thị màu đỏ / "Node not found"

Custom Node chưa được cài, hoặc cài thất bại. Dùng Manager → Install Missing Nodes để phát hiện và cài lại. Kiểm tra log terminal khi khởi động ComfyUI.

Import

Lỗi import khi khởi động: ModuleNotFoundError

Thiếu Python package. Đọc README và log của đúng extension; chỉ chạy dependency trong môi trường Python mà ComfyUI đang dùng. Không áp dụng lệnh pip install -r requirements.txt nếu repo không cung cấp file đó.

Conflict

Xung đột phiên bản giữa các node

Hai extension có thể ghim phiên bản khác nhau của cùng thư viện. --lowvram là tuỳ chọn bộ nhớ, không sửa dependency conflict. Ghi lại version, khôi phục snapshot hoặc cô lập môi trường; rồi gửi log tối thiểu cho maintainer.

Missing

Node cài xong nhưng không thấy trong palette

Quên khởi động lại ComfyUI sau khi cài. Luôn restart server sau mỗi lần cài hoặc gỡ Custom Node để ComfyUI tải lại danh sách.

Khi nào nên cài qua Git URL thay vì Manager?▾

Dùng Install via Git URL khi: node chưa có trong danh mục Manager, bạn muốn cài từ một fork cụ thể, hoặc muốn cài phiên bản đang phát triển (branch dev).

Chú ý: cài bằng Git URL đồng nghĩa với ít kiểm tra tương thích hơn. Hãy đọc README của repo trước khi cài.

Làm sao gỡ cài đặt một Custom Node?▾

Trong Manager, mở tab Installed, tìm node muốn gỡ và nhấn Uninstall. Sau đó khởi động lại ComfyUI. Có thể xóa thư mục trực tiếp trong ComfyUI/custom_nodes/ nếu Manager không hoạt động.
